# ระบบกีฬาสี (GitHub Pages + Google Sheet)

นักเรียนสแกน QR → เลือกห้องและชื่อ → เลือกกีฬา → กรอกสมาชิกทีมสี → ได้ **รหัสแก้ไขทีม**
ระบบจับสลากจัดสาย (เติม BYE ให้อัตโนมัติ) → กรรมการบันทึกผล → ผู้ชนะเลื่อนรอบเอง → สรุปที่ 1/2/3/ชมเชย → ทำเกียรติบัตร

- **ไม่มีการล็อกอิน**: สิทธิ์ดูจาก "ลิงก์/รหัส" ที่ใช้เปิด — วิธีใช้แยกตามบทบาทอยู่ในเว็บที่ `#/help`
- **หน้าเว็บ** อยู่บน GitHub Pages (ฟรี) / **ข้อมูล** อยู่ใน Google Sheet ของโรงเรียน
- ยังไม่ต่อ Google Sheet ก็ลองใช้ได้ทันทีใน **โหมดทดลอง** (ข้อมูลเก็บในเบราว์เซอร์)

## บทบาทและลิงก์

| ใคร | ลิงก์ | ทำอะไรได้ |
|---|---|---|
| ทุกคน | `https://<user>.github.io/<repo>/` | ดูสาย, ดูผล, เปิดทีมด้วยรหัส (สมัครไม่ได้) |
| นักเรียนแต่ละสี | `...?join=<joinKey>` (ทำเป็น QR แยกสี) | สมัครได้เฉพาะห้อง/นักเรียนของสีนั้น สีอื่นลงแทนไม่ได้ |
| ตัวแทนทีม | `.../#/t/<รหัสทีม>` | ก่อนปิดรับสมัคร: แก้รายชื่อได้ / ตลอดงาน: เปลี่ยนตัวได้ทันที ไม่ต้องรออนุมัติ |
| ประธานสี | `...?captain=<captainKey>` | อนุมัติรายชื่อ, ดูและย้อนการเปลี่ยนตัว, ออกรหัสทีมใหม่ (เฉพาะสีตัวเอง) |
| กรรมการ | `...?ref=<refereeKey>` | บันทึกผลบนมือถือ |
| แอดมิน | `...?admin=<adminKey>` | ทุกอย่าง: กีฬา, จับสลาก, ผล, เกียรติบัตร, ตั้งค่า |

ทุกการส่งหรือแก้ไขจะบันทึกในแท็บ `ChangeLog` ว่าใครทำ (ชื่อที่เลือก + รหัส/ลิงก์ที่ใช้) ทำเมื่อไร และเปลี่ยนอะไร
ถ้าลิงก์หรือรหัสหลุด ให้เปลี่ยนค่าในชีต (หรือกด "ออกรหัสใหม่") ลิงก์หรือรหัสเดิมจะใช้ไม่ได้ทันที

## ติดตั้ง

### 1) Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ แล้วไปที่เมนู **ส่วนขยาย → Apps Script**
2. สร้างไฟล์สคริปต์ 4 ไฟล์ แล้ววางโค้ดจากโฟลเดอร์ `apps-script/` ให้ครบ: `Code`, `Api`, `Core`, `Seed`
   - ถ้าต้องการตั้งเขตเวลา: เปิด ⚙️ การตั้งค่าโปรเจกต์ → ติ๊ก "แสดงไฟล์ appsscript.json" แล้ววางเนื้อหาจาก `apps-script/appsscript.json`
3. กลับไปที่ชีต แล้วโหลดหน้าใหม่ จะมีเมนู **กีฬาสี** ขึ้นมา
   - **กีฬาสี → 1) ติดตั้งชีต**: ระบบสร้างแท็บทั้งหมด พร้อมสี 5 สีและรายการกีฬาเริ่มต้น
   - ครั้งแรก Google จะขอสิทธิ์ ให้กดอนุญาต
4. ใส่ข้อมูลจริงในชีต
   - `Classes`: `id` = ห้อง (เช่น `ม.2/1`), `teamId` = รหัสสี (`T1`–`T5` ดูในแท็บ `Teams`)
   - `Students`: `id` (เลขประจำตัว), `prefix`, `firstName`, `lastName`, `classRoom`, `number`, `gender` (`ช` หรือ `ญ`)
   - อยากลองก่อน: ใช้เมนู **กีฬาสี → 2) ใส่ข้อมูลตัวอย่าง** แทน
5. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - คัดลอก URL ที่ลงท้ายด้วย `/exec`

> ถ้าแก้โค้ดใน Apps Script ภายหลัง ต้อง Deploy → **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ไม่อย่างนั้น URL เดิมจะยังใช้โค้ดเก่า

### 2) หน้าเว็บบน GitHub Pages
1. แก้ไฟล์ `config.js` ใส่ URL `/exec` จากขั้นตอนก่อนหน้า
   ```js
   window.SPORTDAY_CONFIG = { apiUrl: 'https://script.google.com/macros/s/xxxx/exec' };
   ```
2. push โฟลเดอร์นี้ขึ้น GitHub แล้วไปที่ **Settings → Pages → Branch: `main` / root → Save**
3. เปิดเว็บด้วยลิงก์แอดมิน (ดูได้จากเมนู **กีฬาสี → ดูลิงก์ทั้งหมด**) แล้วไปที่ **ตั้งค่า & ลิงก์**
   - ตั้งวันปิดรับสมัคร
   - คัดลอกลิงก์ของประธานสีแต่ละสีและกรรมการ ส่งให้แต่ละคนทางช่องทางส่วนตัว
   - กด **โปสเตอร์ QR** เพื่อพิมพ์ติดหน้าห้อง

## รูปแบบการแข่งขัน
- **แพ้คัดออก**: จำนวนช่องในสายปัดขึ้นเป็น 2, 4, 8 หรือ 16 แล้วระบบเติม BYE ให้ทีมที่จับสลากได้ลำดับต้น (เช่น 5 ทีม → สาย 8 ช่อง, BYE 3 ช่อง)
  - ชนะ → เลื่อนเข้าคู่ถัดไปทันที
  - แพ้รอบรองฯ → ไปชิงที่ 3
  - เสมอ → กรรมการเลือกผู้ชนะ (เช่น จากการยิงจุดโทษ)
- **จัดอันดับ** (เช่น วิ่ง): บันทึกที่ 1–3 เป็นรายคน สีที่ส่งนักกีฬาแต่ไม่ได้อันดับจะได้ชมเชย
- แก้ผลย้อนหลังได้ ถ้านัดถัดไปยังไม่ได้แข่ง

## เกียรติบัตร
1. หน้า **สรุปผล & เกียรติบัตร** → กด **สร้าง/อัปเดตรายชื่อเกียรติบัตร** ระบบจะเขียนแท็บ `Certificates` ให้ 1 แถวต่อ 1 คน
   - นักกีฬาที่ถูกเปลี่ยนตัวออกหลังจากได้ลงแข่งแล้ว ยังได้เกียรติบัตร
2. เลือกทำเกียรติบัตรได้ 2 วิธี
   - **ดาวน์โหลด CSV** แล้วนำไปทำ Mail merge เอง
   - **สร้าง PDF อัตโนมัติ**:
     1. ทำแม่แบบใน Google Slides โดยใส่ข้อความ `{{ชื่อ-นามสกุล}} {{รางวัล}} {{รายการ}} {{สี}} {{ชั้น}} {{ปีการศึกษา}} {{โรงเรียน}} {{งาน}}`
     2. ใส่ไอดีไฟล์แม่แบบในหน้าตั้งค่า
     3. กด **สร้าง PDF** ระบบจะเก็บไฟล์ไว้ในโฟลเดอร์ Google Drive

## โครงสร้างไฟล์
```
index.html          หน้าเว็บ (ไฟล์เดียว ใช้ hash routing)
config.js           URL ของ Apps Script (เว้นว่าง = โหมดทดลอง)
assets/app.js       หน้าจอทั้งหมด
assets/client.js    เรียก Apps Script หรือรัน Api.js ในเบราว์เซอร์ (โหมดทดลอง)
assets/demo-db.js   ฐานข้อมูลจำลองบน localStorage
assets/style.css    สี/ฟอนต์ตามดีไซน์ Figma
apps-script/Core.js สายแข่ง, BYE, เลื่อนรอบ, อันดับ, ตรวจรายชื่อ (ใช้ทั้งสองฝั่ง)
apps-script/Api.js  คำสั่งทั้งหมด + สิทธิ์ (ใช้ทั้งสองฝั่ง)
apps-script/Seed.js ค่าเริ่มต้นและข้อมูลตัวอย่าง
apps-script/Code.js เฉพาะ Google: doGet/doPost, อ่านเขียนชีต, เมนู, สร้าง PDF
```

## ทดลองในเครื่อง
```bash
python -m http.server 5317
```
เปิด `http://localhost:5317` แล้วกดป้าย **โหมดทดลอง • สลับบทบาท** มุมขวาล่างเพื่อสลับเป็นประธานสี กรรมการ หรือแอดมิน
